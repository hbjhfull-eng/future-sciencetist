# 무전원 자동 배수 수조 (50L 열림 → 7.5L 남기고 닫힘)

## 파일
- `01_animation_seesaw.html` : 시소(지렛대) + 옆 오리통 방식 (첫 버전)
- `02_animation_integrated.html` : 오리를 마개 막대에 끼운 일체형 + 자석 + 밀폐 연장통 (최종안)
- `tank_calc.py` : 수위·수압·플로트·자석 조건 계산 (`python3 tank_calc.py`)
  - 위쪽 상수(W, H, R, PLUG_D)만 바꾸면 다시 계산돼요.

## 설계 요약
- 수조 안쪽 350x350x500 mm 아크릴 10T, 바닥 R80~100 둥글게, 배수구와 마개는 중심에서 약 60mm 옆(바람개비 오른쪽)
- 50L ≈ 42.0cm, 7.5L ≈ 7.3cm (R100 기준)
- 플로트(오리)가 마개 막대에 헐렁하게 끼워져 있고, 위 턱이 막대를 들어 열고 아래 턱이 끌어내려 닫음 → 열림/닫힘 수위 차이(히스테리시스)
- 자석 2개 + 철판: 아래 자석=닫힘 유지, 위 자석=열림 유지 ("딸깍"), 스프링 없음
  - 조건: 조립 무게 < 위 자석 힘 < 조립 무게 + 플로트 무게
- 막대 끝은 뚜껑 위 밀폐 연장통 안에서만 움직임 (관통 구멍/슬라이딩 O링 없음)
- 입수관은 수평, 7.5L 선 아래 + 역류방지밸브 → 공기가 입수관으로 새지 않음
- 바람개비는 물이 빠질 때(공기 유입)만 회전

## 실제 제작 때 조정할 것
- 자석 간격, 위·아래 턱 위치, 플로트 무게(500g 이상), 마개 크기는 물을 부어 보며 맞추기
